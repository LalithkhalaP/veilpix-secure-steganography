Questions, answered.

Can someone detect a hidden message?

Possibly. LSB changes are subtle to the eye, but statistical tools can sometimes flag them. That is why the message is encrypted first: even if the data is found, it is unreadable without the password.

What happens if I enter the wrong password?

AES-GCM authentication fails, so nothing is shown. VEILPIX never displays ciphertext as text.

Why is PNG recommended?

PNG is lossless, so every pixel bit is preserved. JPEG compression rewrites pixel values and destroys hidden data.

Are my images uploaded anywhere?

No. Everything runs in your browser using the Canvas and Web Crypto APIs. Nothing is sent to a server.

What happens if the image is modified?

Resizing, cropping, filtering, screenshots, or re-saving as JPEG will likely corrupt the payload, and extraction will fail.

Is VEILPIX a professional messaging service?

No. It is an educational project demonstrating AES-GCM with LSB steganography. Do not rely on it for high-stakes secrets.
